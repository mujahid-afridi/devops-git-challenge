# DevOps Git Challenge

## Overview
This repository demonstrates practical Git version control
workflows for a DevOps class activity.

## Objectives
- Initialize a Git repository.
- Track and commit project files.
- Practice branching and stashing.
- Simulate and resolve merge conflicts.
- Use GitHub Pull Requests for collaboration.

## Deployment Script
The `deploy.sh` script demonstrates a basic deployment
workflow using an environment variable.

## Branches
- `main`: Main project branch.
- `development`: Development work.
- `staging`: Staging-related changes.
